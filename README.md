# YIClass iOS

面向 **iOS / iPadOS 26+** 的 Swift 6、SwiftUI 原生课表，使用系统 Liquid Glass、WidgetKit 与深色模式。独立于旧 Flutter 仓库，重新设计书页课表图标，沿用 Apache 2.0 协议。

## 3.1 更新

3.1.12 保留标准锁屏组件作为基础，两门课用两个完整长方形左右并排；仅剩最后一门课时，使用真正横向铺满系统实时活动区域的宽幅卡片。卡片透明，无装饰图标，22 点课名、18 点时间、15 点地点、3 点描边与原生时间进度条。系统不允许实时活动或请求失败时保留普通组件，桌面组件不受影响。设置 → 小组件可关闭“锁屏实时活动”，或选择“仅末课宽幅／当前与后续课程”。新增独立“灵动岛课程信息”开关；关闭后岛内内容置空，但系统仍可能保留活动占位，完全不占岛须关闭实时活动并保留普通锁屏组件。

实时活动的位置由 iOS 安排，不会改变时间下方标准组件格子的大小。每次打开 App 或修改课表，使用 iOS 26 本地排程准备今天与明天的末课，无需推送服务器。系统定时开始接口要求提供提示配置。受单条实时活动最长 8 小时限制，过早的末课预览先保留普通组件，在结束前不超过 7 小时 59 分钟进入宽幅模式。下课过期内容置空，回到 App 时清除活动；系统可能仍保留空活动区域，不保证后台精确到秒删除。

实时活动覆盖锁屏、灵动岛展开／紧凑／最小状态、待机显示及系统转发的小尺寸活动。多课同一宽幅区域左右等宽显示，单课铺满宽度；窄区域保留课名与时间，大区域显示教室。全天课程模式提供卡片内“刷新课程”，直接重新读取共享 JSON，不打开 App，也不凭旧索引跳过课程。后台没有 APNs 服务时，ActivityKit 不提供普通组件那样的课程时间线；下课后若快照已过期，显示刷新入口，避免仍显示已结束课程。前台自动更新；末课仍使用 iOS 26 预先排程。默认“仅末课宽幅”，普通组件继续按系统时间线切课。参考 [Apple ActivityKit 生命周期与更新机制](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) 和 [各展示区域规范](https://developer.apple.com/design/human-interface-guidelines/live-activities)。新 App 图标使用本轮生成的低饱和灰蓝底色、白色书页与课程卡片图形，替换旧图标。

3.1.11 修正单个锁屏组件内挤入两门课的问题：删除半宽双列布局，原“课程安排”和“后续课程”分别用一个完整长方形显示一门课。安装后保留原组件，再从锁屏编辑中添加一个长方形“后续课程”，两块才会占满一行；App 不能自动添加第二块或将单个组件扩大成整行。设置 → 小组件新增折叠的并排说明。参考 [Apple 的组件尺寸与规格](https://developer.apple.com/design/human-interface-guidelines/widgets) 和 [添加锁屏组件步骤](https://support.apple.com/en-mide/118610)。

两门课仍遵循已确认的样式：待上课无常驻边框，正在上的课程用粗递减绕边线；只有一门剩余课时使用较粗完整单课描边。每个组件使用完整单课排版。两门并排时共享字号、行高、留白和圆角，固定预留两行课名，时间与地点位置对齐；不因单门课的节数、周次、时长或标题长短自动缩放。只有展示日整体只剩一门课时才统一切到大号模式。今日结束留白、桌面空态提示、夜间阈值后再切明日等规则沿用 3.1.10。

3.1.10 按确认意见将锁屏双课改为左右并排：无常驻边框、无底色，只有正在上的课程绘制 2.8 点的剩余时间绕边线；单课使用大号排版，描边 2.4 点、上课进度线 3.2 点；自定义进度按预生成的五分钟时间线状态更新。删除电量填充与三分钟下课保留态，课程结束立即移除。桌面大小组件也在仅剩一节时放大课名、时间与地点。

所有组件统一查看当天剩余课程，直到“统一课节时间”中最后一节结束才切换明日，不受当天有没有晚课影响。期间当日已无课程，锁屏输出透明空白，桌面显示“今天没有更多课程”；明日无课则锁屏继续空白、桌面显示“明天没有课程”，不越过明日继续预告后天。时间线加入无课晚间的日终切换点和午夜，不依赖打开主程序；实际更新时间由 iOS 调度。锁屏空白会保留系统已分配的位置，应用不能自行移除该组件。共享组或数据读取异常仍显示同步提示。

3.1.9 修正默认锁屏只显示一节的问题：原“课程安排”标识不变，单个长方形组件默认显示两条课程，课名／时间与地点各成一行；只有一条时使用较大单课布局。新增“单课 · 当前或下一节”，与“后续课程”并排可使用此前草样的大字号双块布局。锁屏去掉默认内容留白并重新控制内部缩进；桌面手动恢复系统内容边距，保留原排版。外框尺寸、时间下方或底部的位置仍由 iOS 锁屏编辑控制。

每个课程块常驻适度圆角的实线细描边：未开始浅色、上课中高亮；上课中的淡透明填充像电量一样自上往下减少，按五分钟进度节点更新。结束后淡显三分钟，再由下一门补位，仍在上课的课程始终优先。主程序的日程及提醒不保留这三分钟完成态。助手收键盘图标内容向下靠，与“截图／文件”共享底部留白，点击区保持 44 点。周视图课程卡片改为先分配完整课名所需行数，再将剩余空间用于地点；长地点不会再挤掉“普通化学实验”等课名。

3.1.8 按确认的草样调整锁屏：保留“课程安排”的既有组件标识，新增“后续课程”，在系统锁屏编辑中添加两者即可并排展示；可按系统提供的位置放在时间下方或底部。透明底色、无装饰图标，显示课名／时间／地点。上课中的课程显示适度圆角的细绕边进度线，每五分钟提供一个进度状态，下课后移除并顺延。系统可能延迟时间线更新；自定义绕边不是每秒动画，系统数字倒计时仍可持续更新。

AI 接入 Chat Completions function calling：`get_schedule_dates` 返回所选日期全天原排课、有效课、停课状态及统一时间 JSON；`get_course_records` 返回指定 UUID 的完整课程记录。涉及日期时首轮必须查询，日期搬课方案的全部源日和目标日都需查询后才能应用。`dateMoves` 在本地从同一执行前快照搬全天课程，包含下午、晚间，保留其他周次和课程 UUID；原目标日另行安排的课程转为未排时间，可与该课程其他已排周次共存。整表方案遗漏已有课程会拒绝并让模型修正一次；明确删除需列出 UUID。保存后的说明由实际变更生成。自定义接口模型需要支持标准工具调用；设备端模式使用展开的日期清单与相同本地调课逻辑。

3.1.7 改进锁屏小组件：长方形优先显示课名、完整时间段和教室，上课中标注状态，跨天标明日期；圆形显示简短课名，距上课或下课一小时内改为倒计时。课表周／日／列表和助手滚动接入系统底栏收起行为。新增本地上课提醒，首次启动请求系统通知权限，默认提前 10 分钟，可在设置关闭或调整为上课时／提前 5、15、30 分钟；按当前课表排程，修改、导入、切换与恢复后更新，避开停课日。最多安排最近 60 条未来提醒，回到前台补排，无需服务器。

3.1.6 支持自定义视觉模型原图输入：JPEG／PNG／GIF／WebP 保留原始字节，以 `image_url` 和 `detail:high` 随用户消息发送；HEIC 等格式在原分辨率转换为 PNG。OCR 只作辅助，识别页可选“修改当前课表”或“导入新课表”，调课通知可调整当前课表。DeepSeek 官方预设更新为 `deepseek-flash`，旧官方 `deepseek-chat`／`deepseek-reasoner` 配置自动迁移；自定义主机的模型名保留。官方请求关闭默认思考、启用 JSON 输出，初始输出上限 16K，截断后自动提高至 32K 重试一次，未完整返回前不应用更改。普通聊天支持不带方案字段的回复，失败不会再把内部提示词或 OCR 坐标塞回输入框。

右上角改为历史记录：保存最近 20 段对话、30 个课表更改前的恢复点，支持继续对话、新建对话、查看并恢复历史状态；恢复动作也会保留当前状态，重启后仍可回退。历史文字保存在本机应用目录，原图不长期归档。输入区内边距缩至 8 点、行间空隙收紧，发送按钮可见圆形 32 点，点击区域仍为 44 点。“截图／文件”可见图标与文字沿 44 点点击区的底部对齐，底部留 6 点，再加面板内边距，修正原先内容垂直居中导致位置偏上的问题。

3.1.5 微调输入区与小组件：输入区按钮底部对齐，发送按钮保持统一的 44 点尺寸，去掉额外按钮样式内边距，键盘弹出时输入区更贴近底部。桌面小组件按旧版排版，顶部状态／日期、主课程／时间／地点、后续两门课程及各自地点。当前周有晚课时直接显示整个晚间分段，无晚课默认折叠，可手动展开；共享组发现和同步逻辑沿用 3.1.4。

3.1.4 恢复旧 Flutter 小组件分支的重签兼容逻辑：从安装后的 embedded.mobileprovision 读取签名服务提供的 App Group 候选，通过系统容器 API 确认实际可访问的组，兼容全能签替换组名。主程序向所有可访问的候选组写入同一快照，小组件读取可访问组中最新的有效快照；课表内容校验继续保留。周视图按可用高度将默认白天八节优先安排在一屏，普通字号行高取 44–64 点，夜间在下方保留露出区域；地点优先完整换行，超长课名在剩余空间显示摘要，可点开完整查看。大字号、极小屏幕或更多白天节次时保留滚动。移除标题下方及课表菜单中的未排课程入口，未排课程仅在列表最底部的“其他课程”内查看，默认收起，不显示数量提示。此修正不授予额外权限，也不读取主程序的私有容器。

3.1.3 调整周视图的时间栏和课程间距：星期与日期表头仅增加纵向高度（68 点），保持列宽；最小课节行高 48 点，上午／下午／晚上间隔 20 点，课程卡片之间保留 8 点纵向空隙。课程名和地点完整换行，按实际文本高度计算行高；空间不足可纵向滚动。默认收起当前周没有课程的晚间尾部，有晚课的节次自动保留，也可手动展开全部晚间课节。日视图和列表的课程按钮改为普通样式，课程名采用系统正文色、教室教师及时间采用次要文字色，跟随深浅色。助手输入区的截图、文件、收键盘与发送按钮点击范围至少 44 点，截图／文件按钮采用更清晰的文字和图标。

小组件在应用回到前台时重新同步，可在设置手动同步并查看结果；读取失败时区分共享权限不可用、未同步和文件无法读取，15 分钟后申请重试。设备包使用临时签名保留主程序与扩展的一致 App Group 声明，同时附带各自的 AppGroup.entitlements；仍须全能签等工具使用有效 Apple 证书及允许该共享组的描述文件重签，临时签名本身不授予 iOS 共享权限。

3.1.2 修复选中文件后无后续处理的衔接：使用 UIKit 负责选择器的展示、关闭与文件回传，读取不再依赖 SwiftUI fullScreenCover 的 onDismiss。助手顶部固定显示文件名及读取／解析阶段，可以取消；90 秒未完成会提示超时，取消后丢弃迟到结果。PDF 解析明确在后台执行。输入区、键盘工具栏和识别文本编辑器提供收起键盘按钮，对话页支持拖动收起，发送及打开文件选择器时自动结束输入。实际 Files 点击和键盘行为待用户实机验收。

- **桌面与锁屏小组件**：下一节课、当天课程、开课倒计时。跟随当前选中的课表，课程、时间设置、导入、AI 应用、撤销后同步刷新。
- **紧凑周／日视图**：日视图独立使用前一天／本日／后一天，点击日期展开原生日历。顶部控件合并，行高按可用高度调整，上午／下午／晚上分段。默认 10 节尽量在一屏内显示；小屏、大字号或更多课节时仍可滚动，所有课程可点击。冲突并排显示。
- **统一课节时间**：默认 **4 + 4 + 2**，每段数量可调。每节开始与结束在同一行。修改开始时间保留该节时长并顺移后续课程；修改结束时间联动后续开始／结束。统一时长与课间立即联动，午休与晚间间隔保留。增减分段节数时同步调整全部课表的节次编号；正在使用的课节不能直接删除。
- **完整导入**：设置 → AI 识别课表，支持截图、图片、PDF、TXT／CSV。PDF 保留星期列与跨页关系；可直接预览结构化课表，也可让已配置的 AI 继续整理。截图使用本机 Vision 识字并附带位置，交给 AI 恢复表格结构。识别源可检查、编辑，再生成方案；新建课表导入，不覆盖原有课表。
- **不丢未排课课程**：没有固定星期、节次的网课、军训等保留名称、教师、地点和周次，在列表的“未排时间”中查看、补充安排。导出再导入也会保留。
- **AI 配置精简**：DeepSeek 快捷设置、用当前未保存配置测试 API。自定义模式不显示／查询设备端兼容性；设备模型状态仅在进入对应配置或主动切换时检查。API Key 存入钥匙串。
- **AI 直接修改**：明确的增删／调课指令直接更新并原子保存课表 JSON，完成后说明变化，可以一键撤销。地点、教师可留空，结合设备日期、时区和学期理解“今天／明天／下周一”等表达。只有关键目标无法确定才追问；单纯咨询建议时给候选，导入新文件时仍保留预览。校验节次、周次与过期状态，截断输出不应用。
- 设置页减少卡片留白和说明。默认跟随系统深色，支持浅色／深色切换，启动背景也有深色资源。

## 导入这类教务 PDF

已将用户提供的两页 PDF 制成回归样本，移除学生姓名与学号；核对脱敏前后课程字符与位置一致。验收逐项比对 **21 条排课安排 + 5 门未排时间课程** 的课程名、教师、地点、星期、节次和周次，包含跨页、单双周、周末及同一课程不同教室。

PDF 未提供明确的学期第一周日期。预览中需要确认“开学日期”，默认继承当前学期；不能凭打印日期推断。所有导入默认沿用统一课节时间。

结构化 PDF 可在本机完成导入。AI 路径使用用户选定的本机模型或自定义接口；实际模型可能误读，因此文件导入保留预览；日常明确修改指令直接保存并提供撤销。图片、扫描 PDF 的文字和布局识别也受原文件清晰度影响。不直接解析 XLSX 或教务网页脚本。

测试方法与实际结果见 [验证记录](docs/VALIDATION.md)。构建通过、PDF 导入通过与真实 AI 服务实测是不同检查，未执行的项不会标为通过。

## Xcode 构建与签名

需要 Xcode 26+、iOS 26 SDK，无第三方依赖。

```bash
open YIClass.xcodeproj
```

选择 `YIClass` scheme。真机签名需要为 **YIClass 与 YIClassWidget 两个目标**配置自己的 Team、Bundle Identifier，并在两个目标启用同一个 App Group。默认共享组为 `group.com.ddyec.YIClassNative`，如需更改，同时修改两个 entitlements 与 `Sources/Shared/SharedLibrary.swift`。重新签名时必须保留小组件扩展和 App Group 权限，否则主程序与小组件无法共享数据。

本地完整课表仍保存在应用支持目录，WidgetKit 使用同一数据的共享快照；共享快照原子写入，在设备首次解锁后可供锁屏小组件读取。共享容器不可用时，设置会显示实际同步错误。

```bash
python3 scripts/validate_project.py
swift test
bash scripts/test-pdf.sh       # macOS：真实 PDFKit 提取与完整导入核对
bash scripts/test-store.sh     # 实际 JSON 文件保存、重启读取与撤销
bash scripts/package-build.sh device
bash scripts/package-build.sh simulator
```

工程由 `scripts/generate_project.py` 确定性生成，新增源文件后需重新生成。`Import and layout review` 工作流在 iOS 模拟器里操作 PDF 预览、导入、紧凑设置与周视图，并保存实际截图。

## 数据与 AI

所有课表共享一个 `TimeProfile`，新建继承当前学期，切换、普通导入、AI 方案均不会回退默认时间。旧 JSON 如果没有时间字段，缺失的信息无法恢复；补设一次后会持续沿用。导出包含统一时间；只有主动采用文件内时间才会更新全局设置。

数据采用原子保存与上一版备份，加载损坏数据时保留原文件并提供恢复。支持课程、日／周／列表、多课表、停课日、单双周、一次撤销。原 Isar 数据库不能直接读取。

“设置 → AI 模式与接口配置”可选择 Apple Intelligence 或 HTTPS OpenAI 兼容接口。DeepSeek 快捷配置为 `https://api.deepseek.com/chat/completions` / `deepseek-flash`。测试 API 仅发送连接检查，不上传课表；识别或对话时，会把相关资料和课表发送到所选远程服务。没有自动云端回退；请求拒绝重定向。Claude／Gemini 原生协议不在本版范围内。设备端需要兼容的机型、地区、语言和已下载模型；iOS 26 本身不保证可用。
