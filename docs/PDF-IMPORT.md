# PDF 导入验收

样本：用户提供的 2026–2027 第一学期两页教务课表。提交的测试 PDF 移除了学生姓名与学号；本地已比对，所有课程字符和位置与原始 PDF 一致。未修改旋转角度、跨页结构或排课内容。

人工基准位于 `Tests/Core/Fixtures/timetable-grid-expected.json`，包含 26 条记录，每条核对课程、地点、教师、星期、节次、周次。不是用解析器输出自动生成的期望值。

- 12 个有排课的课程名称，共 21 条安排；不同教室保留独立记录。
- 5 门未排时间课程：军事技能、军事理论、心理健康、大学生国家安全教育、艾滋病／性与健康教育。
- 普通化学 II：周五第 3–4 节，只在第 4、6、8、10、12 周显示。
- 思想概论晚课：周三第 9–10 节，第 5、7、9、11 周。
- 新时代实践教育第 9 周的教师与课程内容跨两页，必须完整保留。
- 职业发展课程：第 7–8 周周六 1–2 节，第 9 周周六 1–4 节；不能合并成所有周 1–4 节。
- 实验室安全通识教育：周日 1–4 节，第 6–9 周。因此第 8 周周日应有课，即使其他软件的参考截图中没有显示。

`bash scripts/test-pdf.sh` 使用真实 PDFKit 从 PDF 中提取位置、按星期列恢复内容，然后调用生产代码解析，逐条比对人工基准，再校验导入时旧课表与自定义时间未改变，以及导出／重新读取一致。

结构化导入不需要 AI 密钥。AI 路径会获得保留星期列的资料，经过相同的数据校验与预览；真实接口生成质量必须用有效 API Key 另测，不能把本机解析测试当成真实模型通过。

PDF 标明学年与打印日期，但没有明示第一周开学日期。预览默认继承当前学期并允许修改开学日期，不猜测学期起点。
