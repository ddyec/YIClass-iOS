# 日程 JSON

`Application Support/YIClass/day-agenda.json` 是待办与时间安排的唯一主文件。
`library.json` 保留课表及统一课节时间；旧版 `todos` 自动迁移到日程文件，UUID、截止时间、完成状态不变。迁移先落盘日程文件，再备份旧课表并清除其待办副本。运行时 `AppData.todos` 为日程数据的兼容投影，组件共享快照同样由此生成。

示例见 [day-agenda.json](examples/day-agenda.json)。日期必须是含时区的 ISO 8601。`schemaVersion` 为 1；`revision` 由应用在保存时递增。`todos` 包含原始任务，`placements` 用 `todoID` 关联任务，每个任务至多有一个工作时间段。

- `deadline`：最晚完成时间；没有安排工作时间时仍显示在日视图“当天截止”。
- `placements.start/end`：计划去做这件事的时间，结束必须晚于开始，一次不超过七天。跨午夜时会在两天分别裁切显示。
- 无截止、无时间安排的任务显示在日视图“未安排时间”。有截止但没安排的任务继续留在待办页，并在截止当天出现。
- 课程只从当前课表实时计算，不复制到此文件。停课日、周次和统一课节时间沿用课表规则。
- 时间重叠使用独立列，短任务也预留最小可见高度，不盖住其他任务。点击卡片打开课程或待办编辑器。

设置 → 日程与待办可导出、预览并导入此文件。导入会替换日程与待办，保留课表，保存前自动备份，可撤销。格式错误、未知任务引用、重复 UUID、非法时间段整份拒绝；原文件不覆盖。读取失败时显示恢复／导出入口，不静默初始化成空文件。

## AI 接口

`get_todos({todoIDs:[]})` 查询前 100 个任务；指定 UUID 可精确查询。`get_day_agenda({dates:["yyyy-MM-dd"]})` 返回真实课程、工作安排与当天截止任务。

回复 `todos` 可新增任务，附 `scheduledStart/scheduledEnd` 可同时安排时间。`todoChanges` 支持 update/complete/reopen/delete；`agendaChanges` 支持 schedule/remove。remove 仅取消安排，不删除待办。未指定工作时长不自动编造。改动前先查询，任务操作与课程方案分批提交。应用校验执行前快照，整批在同一日程 JSON 中原子保存；出错不应用部分操作。只有本地保存成功才生成保存回执。

## 小组件

新增“待办清单”：长方形显示最紧急任务、截止状态，较高区域显示后续任务；圆形显示未完成数量；行内显示任务摘要。点击打开待办页。共享快照读取故障显示同步提示；午夜与截止时间设置时间线节点，实际刷新由 WidgetKit 调度。
