# 验证记录

日期：2026-10-22。版本：3.1.0 (2)，iOS／iPadOS 26+。

## 自动化范围

`Downloadable iOS builds` 使用 Xcode 26.0.1：

1. 检查确定性工程、App／Widget 源文件、共享 App Group、扩展嵌入、资源与隐私清单。
2. 运行 23 项 Swift 核心测试，覆盖新旧数据兼容、统一时间联动、时长与课间、分段节数调整及课程节次映射、拒绝删除被使用课节、PDF 全量基准、未排课课程保存、Widget 课程时间及课表选择、单双周、停课日、过期 AI 方案、直接修改保存、空地点、设备时区与今天／明天／下周日期上下文等。
3. 用真实 PDFKit 提取测试 PDF，调用生产代码恢复星期列和跨页课程。逐条比对人工核对的 21 条排课和 5 门未排时间课程，再执行导入、导出、重新读取。确认旧课表与用户自定义时间未变。
4. Release 设备归档，生成未签名 IPA。检查真实 arm64 主程序、`PlugIns/YIClassWidget.appex`、WidgetKit 扩展标识、最低系统与资源。
5. 构建通用模拟器 App，检查小组件随主程序嵌入，打包并生成清单／校验和。

[中间版本 5d0739d 的完整打包运行](https://github.com/ddyec/YIClass-iOS/actions/runs/39699014938) 已成功，包含主程序和小组件。当时 21 项核心测试及真实 PDFKit 导入检查通过；随后加入了对全部字段的 26 条人工基准比对，后续运行的该检查也已通过。

PDF 样本的身份处理与逐项验收说明见 [PDF-IMPORT.md](PDF-IMPORT.md)。脱敏前后课程字符和位置一致；没有将原始学生姓名或学号提交到仓库。

## 原生界面检查

`Import and layout review` 使用 Intel macOS runner 和 iOS 26 模拟器，执行原生 UI 操作：打开紧凑设置／课节页、读取真实 PDF、查看导入预览、确认导入、查看第 8 周课程、确认第 10 节可在一屏内看到、查看未排时间课程，并保存截图。

测试入口在 DEBUG 下从测试进程注入同一 PDF，文件读取、PDFKit、结构化解析、预览和应用均调用生产代码。该入口在 Release 中不存在。它不模拟系统文件选择器的权限确认，也不模拟真实 AI 服务响应。

## 尚需设备或凭证的验收

- 真实远程 AI 接口：当前环境没有测试服务的 API Key；API 测试入口已实现，但不能把模型生成质量、鉴权和网络异常列为已实测。
- Apple Intelligence：需要可用设备及已下载模型，尚无真实设备验收。
- 小组件签名与 App Group：无 Apple 签名证书／描述文件，未验证签名后真机桌面／锁屏的实际同步、系统刷新频率和隐私隐藏行为。小组件编译、嵌入与排课计算通过不等于这些行为已验收。
- 大字号、iPad、横屏、VoiceOver、减少透明度及真机 Liquid Glass 视觉检查。
- TestFlight 与 App Store 发布。

旧 3.0 完整 UI 工作流曾因托管 ARM 模拟器启动超时失败。原始记录保留于 [39629560591](https://github.com/ddyec/YIClass-iOS/actions/runs/39629560591)。不能用新的编译结果声称旧完整 UI 套件通过，也不能用 PDF 本机解析测试代替真实 AI 测试。
