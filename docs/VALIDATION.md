## 3.1.6 视觉输入、回复容错与持久历史

对照 [DeepSeek 官方视觉文档](https://api-docs.deepseek.com/guides/vision/) 和 [Chat Completions 协议](https://api-docs.deepseek.com/api/create-chat-completion/)：当前视觉模型为 deepseek-flash，用户 content 支持 text／image_url 数组，high 保留原图。代码更新官方预设与旧官方别名迁移；自定义第三方模型名不重写。JPEG／PNG／GIF／WebP 原始字节直接编码，不缩图；HEIC 等不支持的格式以原分辨率转为 PNG。预览显示原图与干净的 OCR 文本，提供修改当前课表／导入新课表两种目的。设备端仍只接收本机 OCR 文字。

官方 DeepSeek 请求显式关闭默认思考并使用 JSON 输出；初始 16,384 输出 token，收到 length 时提高至 32,768 自动重试一次。截断结果不进入计划解析和保存。返回为空、无 choices、错误协议、服务端拒绝图片时提供可理解的错误信息；普通聊天的缺省 questions／plans 视为空列表，纯文本只展示，残缺 JSON 计划仍拒绝。错误后保留可重试的原请求与附件，输入区仅恢复用户可见说明，不展示内部提示词。

历史记录保存在独立的本机原子文件：20 段对话及 30 个更改前完整 AppData 快照。对话原图不持久化，历史中明确提示需重新附图；课表恢复前可查看课程、课表及统一时间数量，并确认恢复范围。每次恢复都先保存当前状态，重启后可再恢复回来。历史文件损坏时先保留原文件备份，旧版本并无持久历史的操作无法追溯。

新增真实文件集成检查：PNG 经生产图片附件读取后保持相同字节；原图通过 image_url 编码；对话写盘、重新打开、原图不存档；恢复旧课表，再重启并恢复回来。核心检查新增普通对话缺省字段、拒绝不完整计划、图片请求原始字节与标准多模态格式、DeepSeek 参数及第三方配置保留、截断／空正文／畸形响应处理。

输入区位置按用户补充修正：“截图”和“文件”不是缩小点击尺寸，而是将标签内容沿点击区底部对齐（标签底部 6 点留白），使它们在面板内下移；发送按钮的可见圆形 32 点、点击区 44 点。

当前没有真实 AI 服务密钥，没有执行 DeepSeek 在线推理，不能把协议编码检查当作模型理解通知或生成调课结果的实测。自动审批拒绝把用户提供的通知原图复制并提交到 GitHub，理由是测试授权不等于允许将可能敏感内容上传；原图留在本地，不提交仓库，使用无用户资料的 PNG 检查生产附件路径。未运行模拟器 UI 测试，设备界面和实际 AI 生成由用户验收。

## 3.1.4 恢复旧版重签共享组兼容

用户实机确认 3.1.3 仍显示“小组件共享权限不可用”，旧 Flutter 版在同一全能签工具下工作。该错误分支发生在系统 containerURL 返回 nil 时，早于文件读取和 AppData.validate；关闭课表校验无法修复这一分支。

对照 [旧版 SharedGroup.swift](https://github.com/ddyec/YIClass/blob/9fd890ba31ade45b5edd03464d0b261836c84dbd/ios/Shared/SharedGroup.swift) 找到迁移遗漏：旧版从安装后的描述文件提取签名服务替换的共享组，新版只尝试默认组名。本版将旧版候选组发现逻辑移植到主程序和扩展共用的 Sources/Shared/SharedGroup.swift，同时保留默认组和 Info.plist 配置作为回退。

候选描述文件只是发现来源，最终仍由系统容器 API 确认实际访问权限。主程序向所有可访问组写入快照，以兼容 App 与扩展描述文件各自包含额外组的情况；小组件尝试可访问组中的最新有效快照，不修改旧 Flutter 的 YIClass/timetable.json 文件。保持 AppData 校验，缺少权限、缺少文件和无效课表仍区分提示。

用户追加要求避免行高过大，本版同时将周视图改为按屏幕高度拟合白天课节。默认八节白天使用可用高度，普通字号行高限定为 44–64 点；夜间保留少量露出，完整夜间可滚动查看。地点先分配所需空间，超长课程名使用剩余行数显示摘要，不再用最冗长的课程强制撑高全部课节。移除顶部提示条和课表菜单入口，未排课程移到列表最底部默认收起的“其他课程”，不显示数量提示。保留星期／日期表头的纵向留白；大字号或过多课节时优先保持最小可读尺寸，允许滚动。

早期模拟器运行已实际打开紧凑设置和时间页面，并发现 PDF 源文字初始化会错误清除结构化状态，导致预览入口消失；该问题已修正。后续运行因模拟器启动耗时超过测试窗口，没有取得完整导入、日历、深色页面的界面通过结果。因此不将这些界面行为标为已验收。

交付包已包含修正后的生产代码、日视图按天导航与日历、紧凑设置、WidgetKit 扩展；设备归档、核心测试、真实 PDFKit 导入和真实 JSON 文件测试通过。源码、构建清单和下载校验和与交付包对应，用户可以直接签名后验收。

## 尚需设备或凭证的验收

- 真实远程 AI 接口：当前环境没有测试服务的 API Key；API 测试入口已实现，但不能把模型生成质量、鉴权和网络异常列为已实测。
- Apple Intelligence：需要可用设备及已下载模型，尚无真实设备验收。
- 小组件签名与 App Group：无 Apple 签名证书／描述文件，未验证签名后真机桌面／锁屏的实际同步、系统刷新频率和隐私隐藏行为。小组件编译、嵌入与排课计算通过不等于这些行为已验收。
- 大字号、iPad、横屏、VoiceOver、减少透明度及真机 Liquid Glass 视觉检查。
- TestFlight 与 App Store 发布。
