## 3.1.4 恢复旧版重签共享组兼容

用户实机确认 3.1.3 仍显示“小组件共享权限不可用”，旧 Flutter 版在同一全能签工具下工作。该错误分支发生在系统 containerURL 返回 nil 时，早于文件读取和 AppData.validate；关闭课表校验无法修复这一分支。

对照 [旧版 SharedGroup.swift](https://github.com/ddyec/YIClass/blob/9fd890ba31ade45b5edd03464d0b261836c84dbd/ios/Shared/SharedGroup.swift) 找到迁移遗漏：旧版从安装后的描述文件提取签名服务替换的共享组，新版只尝试默认组名。本版将旧版候选组发现逻辑移植到主程序和扩展共用的 Sources/Shared/SharedGroup.swift，同时保留默认组和 Info.plist 配置作为回退。

候选描述文件只是发现来源，最终仍由系统容器 API 确认实际访问权限。主程序向所有可访问组写入快照，以兼容 App 与扩展描述文件各自包含额外组的情况；小组件尝试可访问组中的最新有效快照，不修改旧 Flutter 的 YIClass/timetable.json 文件。保持 AppData 校验，缺少权限、缺少文件和无效课表仍区分提示。

用户追加要求避免行高过大，本版同时将周视图改为按屏幕高度拟合白天课节。默认八节白天使用可用高度，普通字号行高限定为 44–64 点；夜间保留少量露出，完整夜间可滚动查看。地点先分配所需空间，超长课程名使用剩余行数显示摘要，不再用最冗长的课程强制撑高全部课节。移除顶部提示条和课表菜单入口，未排课程移到列表最底部默认收起的“其他课程”，不显示数量提示。保留星期／日期表头的纵向留白；大字号或过多课节时优先保持最小可读尺寸，允许滚动。

新增文件集成检查使用包含 CMS 外层字节的描述文件样本，核对能提取默认组以外的重签组、候选排序／去重、忽略通配符、缺少或损坏描述文件时回退。此检查验证候选解析，不冒充 iOS 已授权或全能签设备实测。本轮继续交付真实设备包，由用户重签后验收。

## 3.1.3 最终排版与小组件同步修正

- 星期／日期表头从 48 点增加到 68 点，保留原有列宽。时段间隔 20 点、课程卡片纵向间距 8 点；默认隐藏没有课程的晚间尾部，可手动展开，当前周的晚课自动保留。
- 卡片的课程名和地点不再设行数限制，使用实际字体与可用列宽计算所需行高；冲突课程并排时保证每条内容有可读的最小宽度。空间不足时使用滚动。
- 日视图与列表改用普通按钮样式和明确的系统正文／次要文字颜色，避免继承按钮紫色。助手输入区的截图、文件、收键盘与发送按钮至少有 44 点点击区域。
- 应用回到前台时重写共享快照并请求刷新，设置提供手动同步、同步时间与错误反馈；小组件区分无共享容器、未同步文件、无法读取文件，失败后申请 15 分钟重试。实际刷新时间仍由 WidgetKit 调度。
- 设备包使用 ad-hoc 临时签名将相同的 App Group 声明写入主程序与扩展，保留各自的 AppGroup.entitlements 文件。构建流程验证签名结构、资源封印，以及 Mach-O 签名中真实嵌入的 XML 权限。此签名不含 Apple 安装授权，仍需全能签等工具使用有效证书与匹配的描述文件重签；工程声明或临时签名本身不代表系统已经允许共享组。

本机文件集成检查新增生产共享快照写入／读取、选中课表和全局时间保留、缺少容器／缺少文件／损坏文件的错误分支。比较对象为已持久化的 JSON 数据，考虑 JSON 日期精度与内存 Date 的差异，不把精度量化误判为课表丢失。
